- No automated test that specifically asserts frame type 0x02 is received (the delta frame probe was done manually)
- UDP chunking not implemented -- stress tests (steady-scale, spawn-burst) cause "Message too long" errors that break replication at high entity counts

## Issues Found
- **Pre-existing: UDP Message too long at scale** -- When entity count exceeds ~1400 per server (bincode serialized > 65KB), UDP replication fails with "Message too long (os error 40)". This breaks shadow replication entirely for the affected server. Not related to delta compression.
- **Pre-existing: Test runner localhost assumption** -- multi-client and peer-replication tests cannot run against remote boards because the runner hardcodes `localhost` for metrics and coordinator API endpoints.
- **Pre-existing: crash-recovery test** -- Fails because the test kills a process that can't be restarted from the test runner.
