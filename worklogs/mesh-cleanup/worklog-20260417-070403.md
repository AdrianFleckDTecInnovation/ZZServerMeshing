### WI-141: Extract `spawn_and_track_ownership` helper

- `crates/sim-server/src/systems/input.rs`: Added `fn spawn_and_track_ownership(world, state, client_id)` helper that combines `spawn_from_entity_state_direct` + `EntityOwnership` insertion. Replaced both inline patterns (SpawnEntity and SpawnPlayer handlers) with calls to the helper.

### WI-142: Extract `enqueue_outbound` helper

- `crates/sim-server/src/systems/mod.rs`: Added `pub(super) fn enqueue_outbound(messages, addr, msg)` that calls `serialize_versioned` and pushes to the provided messages vec. Single helper works for both `OutboundForwards` and `OutboundTransfers` since they have identical `messages: Vec<(SocketAddr, Vec<u8>)>` structure.
- `crates/sim-server/src/systems/input.rs`: Replaced 5 inline serialize+push patterns with `super::enqueue_outbound(...)`. Removed `use crate::game_loop::serialize_versioned;` import (no longer needed in production code; test `deserialize_versioned` is unaffected).
- `crates/sim-server/src/systems/transfers.rs`: Replaced 2 inline serialize+push patterns. Removed `use crate::game_loop::serialize_versioned;` import.
- `crates/sim-server/src/systems/drain.rs`: Replaced 1 inline serialize+push pattern. Removed `use crate::game_loop::serialize_versioned;` import.

Note: Named `enqueue_outbound` instead of separate `enqueue_forward`/`enqueue_transfer` since both queue types have identical structure and a single function is cleaner.
