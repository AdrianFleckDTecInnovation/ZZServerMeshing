## Design Decisions
- Used `ring` crypto backend for rustls instead of the default `aws-lc-rs`. The aws-lc-sys crate requires CMake + C compiler for cross-compilation, which would fail for the armv7 target. ring is pure Rust and cross-compiles cleanly.
- The handler logic is shared via a generic function `handle_http_request<S>` rather than duplicating it. Both TcpStream and TlsStream<TcpStream> implement AsyncRead + AsyncWrite.
- No changes needed to client code. The client already uses relative `/assign` when VITE_COORDINATOR_URL is empty, which works for same-origin HTTPS.
- TLS is only on the HTTP/client-serving port (7871). The WebSocket port (7870) for sim-server connections stays plain TCP since those are internal mesh traffic.
