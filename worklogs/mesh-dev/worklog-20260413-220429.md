## Changes Made

### Finding #028: Dual authority during transfer window
- `crates/sim-server/src/systems.rs`: Added `Without<TransferOutbound>` filter to 5 system queries:
  - `npc_behavior` -- stops NPC AI on frozen entities
  - `physics_integration` -- stops physics simulation on frozen entities
  - `clamp_positions` -- stops clamping frozen entities
  - `prepare_replication` -- stops UDP replication of frozen entities (target server replicates)
  - `prepare_client_snapshot` auth_query -- frozen entities excluded from auth data; clients see shadow data from target instead

### Finding #031: Player input lost during transfer window
- `crates/sim-server/src/systems.rs`: `process_client_inputs` MoveInput handler now checks for `TransferOutbound` before local processing; if present, forwards input to `target_addr` via UDP `ForwardedInput` instead of applying locally
- `crates/sim-server/src/systems.rs`: `drain_inbound_events` forwarded input handler now checks for `TransferOutbound`; if present, re-forwards input to target server

### Finding #030: Transfer retry uses stale state
- `crates/sim-server/src/components.rs`: Removed `serialized_msg: Vec<u8>` from `TransferOutbound` struct; updated doc comment to describe frozen semantics
- `crates/sim-server/src/systems.rs`: `process_transfer_timeouts` now reads current Position, Velocity, EntityKind, NetworkId, LastInputSeq from ECS and builds a fresh `AuthorityTransfer` message for retry instead of re-sending stale bytes
- `crates/sim-server/src/systems.rs`: `process_transfers` and `process_drain` no longer store `serialized_msg` in TransferOutbound (removed `.clone()` on bytes)
- Updated 10 tests that constructed `TransferOutbound` with `serialized_msg` field

### Finding #029: Chunk reassembly memory leak
- `crates/sim-server/src/receiver.rs`: Added global reassembly sweep every 100 loop iterations; evicts all reassembly entries older than 40 ticks behind the global max tick from ANY server; catches crashed peers whose per-server tick never advances
- Added `GLOBAL_SWEEP_INTERVAL` (100) and `GLOBAL_STALE_TICKS` (40) constants
- Added tracing::debug log when entries are evicted

### Test updates
- `crates/sim-server/src/schedule.rs`: Updated `transferred_entity_remains_until_ack` test to expect replication to exclude TransferOutbound entities (was asserting 10, now asserts `10 - outbound_count`)
- `crates/sim-server/src/components.rs`: Updated `transfer_outbound_component_query` test to remove `serialized_msg` assertions
