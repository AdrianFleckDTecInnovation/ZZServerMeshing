## Architecture Summary
Before:
  World (HashMap) -> Arc<RwLock<World>> shared by all async tasks
  simulation.rs monolithic game loop with manual phase ordering

After:
  bevy_ecs::World owned exclusively by game loop thread
  Async tasks communicate via SharedInbound/SharedCoordEvents lock-free swap buffers
  12 ordered ECS systems in a Schedule, run synchronously each tick
  EntityState stays as wire format; components are the internal representation
