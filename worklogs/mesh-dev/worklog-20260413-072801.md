## Design Decisions
- Used `ring` crypto backend for rustls (same as coordinator). Avoids aws-lc-sys C compilation that breaks aarch64 cross-compilation.
- Extracted `handle_client<S>()` as a generic function rather than using trait objects. WebSocketStream<TcpStream> and WebSocketStream<TlsStream<TcpStream>> are different concrete types, so the accept loop spawns the appropriate variant and both call the same generic handler. This avoids Box<dyn ...> overhead and keeps the code clean.
- The `tls` field defaults to `false` via `#[serde(default)]` so old sim-servers without TLS continue to work with a new coordinator.
- Same cert is shared between coordinator and sim-servers. The SANs include all board IPs so browsers accept the cert regardless of which server they connect to.
- TLS is only on the WebSocket port (client-facing). UDP peer replication stays plain -- it's internal mesh traffic.
