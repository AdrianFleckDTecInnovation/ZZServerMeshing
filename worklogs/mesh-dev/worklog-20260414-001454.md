## Changes Made

### Issue 1: prepare_replication includes TransferOutbound entities
- `crates/sim-server/src/systems.rs`: Removed `Without<TransferOutbound>` from the `prepare_replication` query. TransferOutbound entities are now replicated to peers so shadows stay up-to-date for crash recovery. The target server will have both its own authoritative copy AND a shadow from the source -- `drain_inbound_events` already skips peer updates for entities it owns.
- `crates/sim-server/src/systems.rs`: Renamed test `replication_excludes_transfer_outbound_entities` to `replication_includes_transfer_outbound_entities` and updated assertion from `len() == 2` (excluded) to `len() == 3` (included).
- `crates/sim-server/src/schedule.rs`: Updated `transferred_entity_remains_until_ack` test to assert replication includes all 10 entities instead of `10 - outbound_count`.
- `crates/sim-server/src/components.rs`: Updated TransferOutbound doc comment to say "STILL replicated" instead of "excluded from replication".

### Issue 2: SHADOW_STALE_TICKS increased to 300 (15 seconds)
- `crates/sim-server/src/systems.rs`: Changed `SHADOW_STALE_TICKS` from `TICK_RATE * 5` (100) to `TICK_RATE * 15` (300). Added comment explaining the 15s margin over worst-case crash detection (10s).
- `crates/sim-server/src/systems.rs`: Updated `shadow_cleanup_removes_stale` test tick from 200 to 400 (past new threshold).
- `crates/sim-server/src/systems.rs`: Updated `shadow_cleanup_at_exact_threshold` test comment from "(100)" to "(300)".
- `crates/sim-server/src/schedule.rs`: Updated `stale_shadow_included_in_snapshot_then_cleaned` test tick from 200 to 400.

### Issue 3: RecoverEntities aborts transfers to dead server
- `crates/sim-server/src/systems.rs`: In `process_coord_events`, after the shadow promotion loop in the RecoverEntities handler, added a second pass that queries all entities with `TransferOutbound` and removes the component if `target_server == dead_server_id`. Logs "Aborting transfer for entity {eid} to dead server S{dead_server_id}" for each.
