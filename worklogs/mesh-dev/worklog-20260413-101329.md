## Changes Made

### #018: Baseline drift on dropped frames (high)
- `crates/sim-server/src/systems.rs` (`prepare_client_snapshot`):
  - Restructured the per-client loop to use `match handle.tx.try_send(frame)` with three arms
  - Full snapshot path: `build_baseline` called only in `Ok(())` arm; on `Full`, baseline cleared to None
  - Delta path: `update_baseline` called only in `Ok(())` arm; on `Full`, baseline cleared to force full snapshot next tick
  - `ticks_since_full` only incremented on successful send
  - On any dropped frame (Full channel), the baseline is cleared entirely, guaranteeing the next tick sends a full snapshot for immediate convergence

### #023: Ghost entities from baseline/removal mismatch (high)
- `client/src/world-view.ts` (`interpolate`):
  - Added `STALE_ENTITY_THRESHOLD_MS = 6000` (6 seconds, slightly above the 5-second full snapshot interval)
  - In `interpolate()`, before per-entity interpolation, checks `now - entity.lastUpdateTime > 6000ms`
  - Stale entities are deleted from the entity map (except the local player, whose position is managed by the prediction system)
  - This is defense-in-depth: even if #018 prevents most ghost entities, any entity not refreshed within 6 seconds is garbage-collected client-side

### #024: Full snapshot cloned per client (medium)
- `crates/sim-server/src/resources.rs`:
  - Added `ClientFrame` enum with `Shared(Arc<Vec<u8>>)` and `Owned(Vec<u8>)` variants
  - Added `as_bytes()` and `into_vec()` methods on `ClientFrame`
  - Changed `ClientRegistrationEvent.tx`, `ClientHandle.tx`, `ClientRegistry::register_from_event` to use `Sender<ClientFrame>` instead of `Sender<Vec<u8>>`
- `crates/sim-server/src/systems.rs`:
  - `encode_binary_snapshot` result wrapped in `Arc::new()`; backward-compat `ClientSnapshot.frame` gets a single `(*full_frame).clone()`
  - Full snapshot sends `ClientFrame::Shared(Arc::clone(&full_frame))` -- zero-copy for all clients
  - Delta sends `ClientFrame::Owned(...)` -- unique per client
- `crates/sim-server/src/network.rs`:
  - `handle_client` channel type changed to `mpsc::channel::<ClientFrame>`
  - Frame receive loop calls `client_frame.into_vec()` to extract bytes for WebSocket send
  - `into_vec()` uses `Arc::try_unwrap` (avoids clone if this is the last reference)
